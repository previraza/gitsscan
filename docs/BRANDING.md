# Branding Strategy

## Name
- Primary: `GitSScan`
- CLI command: `gitss`

## Slogan
- "Scan fast. Sync safe."

## CLI identity
- Minimal and bold terminal-first output
- Stable symbols: `✓` clean, `●` pending, `✗` no-git
- Safety-first language for destructive actions

## ASCII logo

```text
  ____ _ _   ____  ____
 / ___(_) |_/ ___|/ ___|  GitSScan
| |  _| | __\___ \\___ \  Scan fast. Sync safe.
| |_| | | |_ ___) |___) |
```

## Visual direction
- Palette: green/amber/red states + neutral cyan metadata
- Typography: monospace-first
- Tone: pragmatic, sysadmin-friendly
